# 航旅纵横 · 2026 年度飞行报告

[打开交互 Demo](https://wbj5322-arch.github.io/flight-memories-2026/)

设计尺寸 1125 × 2436 px。场景等比铺满手机可用区域，允许裁切边缘；文字与操作区等比缩放到可视安全区，保留原文字和区内排版。横纵缩放比例始终一致，没有拉伸、镜像或拼接层。机票在固定大小的画布内推进，透明窗口与原图保持同步；下一页提前在下层完成绘制，再从窗口连续显露，避免整页裁切与超大缩放图层反复重绘。手机使用独立的轻量图片，原始图片继续保留；支持 AVIF 的浏览器优先使用更小的文案图，其余浏览器自动使用 WebP。

加载界面与原稿数字直接包含在入口页面中；主脚本及开始页—机票—水面页的完整首段资源下载时，按实际接收进度更新 0–99%；首段已准备好可连续播放后显示 100%。下载停滞会自动重试，持续失败展示原有重试按钮，图片解码等待也有时限。首段资源优先加载，春夏资源从启动时同时进入后台预载，提前准备动画纹理。特写大图在其后加载，避免占用翻页所需带宽。首次进入前 5 秒显示静态加载画面和进度；超过 5 秒仍未完成才播放原来的舷窗动画。翻页等待不足 5 秒不展示加载动画，超过 5 秒复用原来的加载界面，完成后自动进入下一页。图片与脚本使用独立文件和内容版本号，便于浏览器缓存。

GitHub Pages：main 分支，根目录 / (root)。部署时完整上传本目录的全部文件。
