# 航旅纵横 · 2026 年度飞行报告

[打开交互 Demo](https://wbj5322-arch.github.io/flight-memories-2026/)

设计尺寸 1125 × 2436 px，整张画面按手机可用宽高统一映射，完整铺满可用区域。不同屏幕长宽比会改变整幅画面的显示比例；保留全部内容、原文字和相对排版。没有镜像、延展或拼接层。机票窗口与下一页遮罩同步推进，过场覆盖后退出开始页，下一页连续接管画面。手机使用独立的轻量图片，原始图片继续保留。

加载界面直接包含在入口页面中；开始页资源优先加载，后续页面自动预载。首次进入前 5 秒显示静态加载画面和进度；超过 5 秒仍未完成才播放原来的舷窗动画。翻页等待不足 5 秒不展示加载动画，超过 5 秒复用原来的加载界面，完成后自动进入下一页。图片与脚本使用独立文件和内容版本号，便于浏览器缓存。

GitHub Pages：main 分支，根目录 / (root)。部署时完整上传本目录的全部文件。
